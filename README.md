### Светодиоды
     - BLE
        - есть подключение - горит - нет подключения - погашен
        - нет связи с модулем BLE(сгорел или не прошит) - мигаем один раз в период
        - нажата кнопка PUSH и сброшен пароль на 123456 - 3 раза мигаем(мигаем только при исправном)
     - ERROR
        - 1 - нет связи с датчиком Энкодера
        - 2 - ошибка драйвера мотора FAULT - например нет питания
        - 3 - слишком малая позиция при старте
        - 4 - обрыв ремня при старте - превышена максимальная позиция
        - 5 - обрыв ремня во время работы - превышена максимальная позиция
        - 6 - нет разгона - есть такая мулька
        - 7 - большая масса створки

     - UPS
        - переход на резерв - на АКК                    - горит светодиод
        - напряжение менее 22В  - пониженное от АКК     - мигаем 3 раза
        - напряжение менее 22В  - питание от Сети       - мигаем 1 раза

      - пакетник - индикация режимов пакетника -
            режим пакетника - зажикаем светодиод
            режим BLE - миаем один раз в период (толко выход частичное открытие - мигаем 2 раза)
        - 1 - Автомат
        - 2 - Открыто
        - 3 - Закрыто
        - 4 - Только выход
        - 5 - Частичное открытие
